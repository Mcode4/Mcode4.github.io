About Me

I'm a software engineer specialized in web development. I completed App Academy's 960-hour full-time software engineering program (Sep 2024 – Mar 2025) and have built projects since, including paid freelance work in 2026. I'm passionate about coding and learning new things. Some of my key points are listed below.

Stack

I primarily work with HTML, CSS, and JavaScript, which I consider the core of web development. These technologies enable me to create responsive, accessible, and visually appealing websites, and I value them as essential skills for building the applications.

API Control

I've experimented with and implemented RESTful APIs while creating apps. One being a superhero API that fetched data on a character. This allowed me to create an application without the need of a backend.

Code-to-Cloud

My earlier projects listed below were deployed to the internet with Render. I've also worked with Docker, AWS, and GitHub Pages.

Systems Thinking

Starting a project, I get a feel of what the structure should be and data should flow. I usually keep the frontend and backend in separate folders, with data flowing from the database through the backend API to the frontend.
