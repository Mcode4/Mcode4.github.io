# Marcellies Armstrong - Portfolio

Personal portfolio site for Marcellies Armstrong, a software engineer based in Columbus, GA.
Live at https://mcode4.github.io/

## What's on the site
- **Home** - intro, about me, tools and technologies, projects, and a contact section
- **More About Me** (`aboutme.html`) - background, including App Academy's 960-hour full-time software engineering program (Sep 2024 - Mar 2025)
- **Tools & Languages** (`techstack.html`) - the technologies I work with
- **Project pages** (`projects/`) - write-ups for Capstone Academy, Nom Now, and Spot Homes
- **Featured projects** - Home Tools 2 (freelance, 2026), Omni, Capstone Academy, Nom Now, Spot Homes

## Built with
Static HTML, CSS, and JavaScript (jQuery), hosted on GitHub Pages. The contact form sends mail through EmailJS.

## Running locally
No build step. Open `index.html` in a browser, or serve the folder with any static file server.
